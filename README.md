Meu site pessoal, feito **do zero por mim**, para reunir um pouco de quem eu sou, o que venho aprendendo e, principalmente, o que já estou colocando em prática.

Hoje trabalho como **Analista de Sistemas na Linx Goiânia** e estou cursando **Análise e Desenvolvimento de Sistemas**, com o objetivo de evoluir cada vez mais como desenvolvedor **Full Stack**.

Não queria fazer mais um portfólio igual a tantos outros, cheio de cards brancos, gradientes aleatórios e uma estrutura genérica. Queria que o site tivesse personalidade e um pouco da minha cara.

Por isso veio a ideia da **teia de aranha**, do cursor personalizado, das animações e da identidade mais escura com detalhes em vermelho. É uma referência visual que representa bem a forma como gosto de construir as coisas: conectando ideias, tecnologias e experiências.

## 🛠️ Tecnologias

O projeto foi construído utilizando:

- **React 19** + **TypeScript**
- **Vite** para build e desenvolvimento
- **Tailwind CSS 4** para estilização
- **Framer Motion** para animações e transições
- **Lucide React** para os ícones
- **WebGL** puro, no Hero, para o efeito de reveal entre o vídeo e a foto

## 🚀 O que você encontra por aqui

A ideia não é simplesmente listar tecnologias. Quero mostrar um pouco da minha trajetória e do que venho construindo.

- 🕷️ **Hero imersivo em tela cheia**, com um vídeo de fundo que revela minha foto conforme o mouse se move
- 👨‍💻 **Sobre mim**, com minha stack e um pouco da minha trajetória
- 💼 **Experiência profissional**
- ⚙️ **Habilidades técnicas**, organizadas por categoria e nível
- 📁 **Projetos em destaque** e coisas que já coloquei em prática
- 📩 **Formulário de contato**

O portfólio ainda está em evolução — assim como eu.

O formulário de contato, por exemplo, ainda não está conectado a um backend. Por enquanto ele apenas impede o reload da página. A próxima etapa é transformar isso em uma função **serverless na Vercel** e deixar o fluxo realmente funcional.

## 💻 Rodando localmente

Se quiser clonar o projeto e dar uma olhada no código:

```bash
npm install
npm run dev
```

Depois, acesse:

```text
http://localhost:5173
```

Outros comandos disponíveis:

```bash
npm run build     # gera o build de produção
npm run preview   # executa o build localmente
npm run lint      # análise de código com oxlint
```
